俳句の裾野（Firebase 版）を公開する手順
==========================================

このフォルダをそのまま使います。やることは、3つのコマンドだけです。

0. 準備（最初の1回だけ）
   Node.js を入れます。 https://nodejs.org/ja の「LTS」をダウンロードして、
   そのまま「次へ」で進めてインストールします。

1. このフォルダで PowerShell をひらく
   エクスプローラーでこのフォルダ（haikunosusono）をひらき、
   何もないところを Shift を押しながら右クリック →
   「PowerShell ウィンドウをここで開く」（「ターミナルで開く」でも可）。

2. 次の3行を、1行ずつ打って Enter（コピー＆貼り付けで大丈夫です）

   npm install -g firebase-tools
   firebase login
   firebase deploy

   ・firebase login では、ブラウザが開くので、Firebase を作った Google アカウントでログインし、「許可」を押します。
   ・firebase deploy が終わると、最後に
       Hosting URL: https://haikunosusono.web.app
     と出ます。これが、仲間に送るアドレスです。

3. 直したものを公開しなおすとき
   新しい public フォルダの中身を入れかえてから、PowerShell で
   firebase deploy
   とだけ打ちます。
   （PowerShell で firebase が動かないときは、  firebase.cmd deploy  と打ちます。）
   firebase.json が入っている、いちばん内側のフォルダ（haikunosusono）で打ってください。

部屋の名前（この版から）
   ひとりで句会   自分とボット（2〜4名）の句会。自分の句がストッ句に残り、参加した句会として数えられる。招待・見学なし
   だれでも句会   毎晩20時「夜8時だよ、全員集合」。土日は朝10時の回も。お題は「当季雑詠」。受付は1時間前から。
                  （ほかの人の句の無断公開は禁止の告知つき）。ひとりのときは、ボットが2名加わる（ふたりのときは1名）。
                  毎回、はじめにチュートリアルが開く。進行の目安の時間つき。最高点の人に句碑のトロフィー
   仲間と句会     合言葉か招待リンクで集まる、メンバー限定（見学なし）。題はひとり1題
                  （ランダム・候補・当季雑詠・雑詠もOK）かボット出題。ふつうは1回戦に
                  ひとり1句（パス可）。だれが出していないかが見え、全員そろうと幹事に
                  「では、すすめてください」の合図。選の種類（特選1並選3予選／秀句1佳作3
                  予選／天・地・人・並・予選）と句数・点数は幹事が設定、途中でも可変
                  （全員に「可変タイム」のお知らせ）。回数の上限は3〜10回戦か制限なし。
                  点は通算にくりこされ、まわし終えるか幹事が「とじる」と、通算トップが
                  句会優勝トロフィー。参加者だけの「こそこそ話」つき
   句会アーカイブ 参加した句会だけが、あとから見られる
   句会の評のヒント 選評のヒント帳

定例句会のしくみ（知っておいてください）
   ・時刻で自動に動くサーバーは、使っていません。定刻に、「句を出した人」のページが開いていれば、そのページが
     句会をはじめます（句を出したら、ページを開いたままお待ちください）。開いていなければ、だれかが開いた時点で、
     すぐはじまります（定刻から3時間をすぎた回は、不成立として閉じます）。
   ・土日の朝10時の回も、しくみは同じです。
   ・定刻の10分あと（遅れて参加OK）までに、だれも句を出さなかった回は、ひらかれません。
   ・ボットの句は、あらかじめ用意した句（季節ごとに8句）です。ボットの選評も、決まった言いまわしです。
   ・仲間と句会の「合言葉」は、おなじ言葉を入れた人がおなじ部屋に入る仕組みです。かんたんな言葉だと、
     知らない人と合言葉がかぶることがありえます。仲間うちだけで通じる言葉をおすすめします。
   ・時刻は、各自の端末の時計で見ています。端末の時計が大きくずれていると、受付や開始のタイミングがずれます。
   ・句を出した人が、全員ページを閉じたままだと、進みません（だれかが開き直すと、つづきから進みます）。

firestore.rules が新しくなりました（pub という、人数だけの公開の記録を追加）。
   Xのお礼つぶやき（「参加は〇人でした」）のためです。firebase.cmd deploy で、一緒に反映されます。

見え方のきまり（画面での制限です。データそのものを隠す仕組みではありません）
   見学の線引きは、画面の表示で行っています。もっと厳密に閉じる（ほかの人が仕組み上も読めない）には、
   firestore.rules を、参加者だけが読める形に変える必要があります。必要になったら、ご相談ください。

中身
   public/            公開されるページ一式（index.html、shim.js、firebase-config.js、vendor/）
   firestore.rules    データの読み書きのきまり（deploy で一緒に反映されます）
   firebase.json / .firebaserc   設定（さわらなくて大丈夫です）

バージョンの印
   画面の日付の横に、小さく「v2026.10.11a」のような版の名前が出ます。
   新しい zip を deploy したあと、この印が変わっていれば、入れかえ成功です。

■ 見学モード（登録まえの体験）v2026.10.11c から
・ログインの扉に「登録せずに、まずは見てみる」がつきました。
・登録なしでできること：俳句とは？のチュートリアル／体験句会（ボット相手・保存なし）／句づくり。
・登録しないと：句は保存されず、句会への参加・閲覧もできません（画面に「登録してはじめる」ボタンが出ます）。
・句づくりは「フレーズ十二音＋季語五音」のかんたんな型になりました（パズル式はやめました）。

■ 講評（合評）の壇上方式 v2026.10.11d から
・だれでも句会の合評は、一句ずつ「いま壇上」のカードで、ゆっくり話す方式になりました（一句5分）。
・講評のまえに「みっつのおやくそく」（敬意・ひとことコメント・無断公開きんし）が出ます。
・司会（蛙）が、句ごとに問いかけ（「どんな景色が見えましたか？」など）で、ことばをうながします。のこり1分でも声をかけます。
・人のコメントには「🫶 わかる」を押せます（参加者のみ）。
・見学の人数が「👀 見学中・◯人」と出ます。

■ v2026.10.11g の追加
・ふらっと句会（🍡）：いつでも、3人そろったら即スタート。ボット2名＋司会の蛙が必ず参加（5句）。選句10分・講評は一句8分（ゆっくり）。だれかが抜けてもタイマーが進行。句はストッ句へ。
・講評のにぎやかし：紅先生（赤ペン・的確な指摘＋かならずほめる）、ひなた（やさしくほめまくる）、はま吉（ときどきつっこみ）。すべてオリジナルキャラ。
・講評に、スタンプ（🌸すき 👏うまい 😮おどろき 🍵しみじみ）、定型文ボタン、コメントへの返信。
・みっつのおやくそくは、仲間と句会にも（選句・合評中に表示）。
・ストッ句の専用ページ（マイメニュー「ストッ句」）：表（よこ書き）／短冊（たて書き）切りかえ、しぼりこみつき。
・デザインをかわいく：丸ゴシック（Zen Maru Gothic）、まるいボタン、パステルの部屋タブ。句の表示は明朝のまま。

■ v2026.10.11h の追加（朝の実戦をうけて）
・選句をほんものの句会の順に：① ✓きになる（予選・3句まで）→ ② ○すき（並選）→ ③ ◎いちばん（特選）。
・特選なし・並選だけ・✓だけでも「選を終了」できる（どれかひとつでOK）。
・「選び終えました」のあとも、時間内なら「選びなおす」で変えられる。
・講評の司会は「ダー浜（つっこみ司会・ボット）」に。問いかけ・のこり1分の声かけも関西弁のきびしめで。

■ v2026.10.11i の追加（新しい時間割ほか）
・定例句会（デモ）の時間割：毎晩21時「いつもの句会」＋23時「おかわり句会」。土・日・祝日は、10時（あさ）・13時（昼から）・15時（おやつどき）の「いつもの休日句会」も。合言葉は「夜9時だよ、全員集合」。
・祝日は、内閣府の一覧（2026・2027年）をアプリに内蔵。年がかわったら index.html の JP_HOL と、Botの post.js の JP_HOL に足す。
・トップの定例カードを「次回の歌会」ふうの大きな表示に。部屋に「きょうの時間割」も。
・「✏️ おもいつ句」（句材メモ）：トップでいつでも何こでもメモ→「ストッ句へ」で推敲つきの句に（1日の制限なし）。
・初心者部屋は、1日に何句でもOKに。
・講評のコメントは、新しいものが上（ツイッターふう）。紅先生の指摘の語彙も増量（季語が動く・三段切れ・つきすぎ・散文的など）。
・Xボットも新時間割に対応：bot の post.js と .github/workflows/tweet.yml を、GitHubで貼りかえること（zipの中の2ファイル）。

■ v2026.10.11j：時間割の手直し

・土・日・祝日：10時（あさ）・13時（昼から）・15時（おやつどき）の3回だけ（休日の夜はおやすみ）
