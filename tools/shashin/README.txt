写真づくりの道具（つぶやき・note 用）
====================================
img/parts/（できること紹介）と img/meiku/（名句の句碑の見本）の写真を、アプリ本体の描く仕組み（短冊・句碑）と、
アプリの画面そのものから作る道具です。開発AIが使います。ふだんは、さわらなくて大丈夫です。

しくみ
・app/public をコピーして、ログインと保存先を「にせもの」（fakeshim.js・seed.js）に差しかえ、ネットにつながずに動かします。
  画面に出る「裾野もみじ」さんと、その句は、写真用の見本です（開発AIが作った句。だれかの句ではありません）。
・build1.js … 短冊・句碑のくらべ写真と、名句の句碑の見本（季節ごとに20枚）
・cap.js → build2.js … アプリの画面をとって、スマホの枠にならべた写真
・名句は、アプリの MEIKU から、芭蕉・蕪村・一茶・子規・漱石・千代女・去来・凡兆・其角・嵐雪だけを使います。
